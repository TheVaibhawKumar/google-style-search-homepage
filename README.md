# Google‑Style Search Homepage (Brand‑Neutral)

Responsive, accessible search homepage inspired by Google’s layout, using inline SVG icons. Deployed via GitHub Pages.

## Features
- Responsive center layout with header, search box, actions, and footer.
- Inline SVG icons for search, microphone, and image, no external CDNs.
- Brand‑neutral: no Google trademarks, logos, or wordmarks.
